\# CodeAlpha Phishing Awareness Training



\## Project Overview



This project is a cybersecurity awareness training module developed for the CodeAlpha Cyber Security Internship.



The module teaches users how to identify phishing emails, fake websites, and social engineering attacks.



\## Features



\- Explanation of phishing attacks

\- Email phishing awareness

\- Fake website awareness

\- Common phishing warning signs

\- Suspicious phishing email example

\- Social engineering techniques

\- Practical safety recommendations

\- Interactive phishing awareness quiz

\- Security checklist

\- Responsive web design



\## Technologies Used



\- HTML5

\- CSS3

\- JavaScript
